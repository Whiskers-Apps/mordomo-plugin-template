# Plugin Template
## Modifying
Change the content of `manifest.json`. You will need a unique ID for the plugin.

## Installing
Run the `make release` command to compile the project and properly copy the jar to correct place. 

## Running
After compiling the plugin you can go to mordomo settings (Dev Tab) and re-index or start/stop if you already have it indexed.
Then you just need to assign a keyword to run your plugin in the plugins tab.
